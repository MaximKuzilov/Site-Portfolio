# Портфолио Максима Кузилова

Персональный сайт-портфолио Full-Stack разработчика и SEO-специалиста Максима Кузилова. Сайт знакомит с профессиональным опытом, ключевыми компетенциями и реализованными проектами в области веб-разработки, мобильных приложений, десктопного программного обеспечения и поисковой оптимизации.

## Возможности сайта

- каталог проектов с отдельными страницами и подробным описанием работ;
- галереи изображений, ссылки на действующие проекты и файлы для скачивания;
- русская и английская версии интерфейса;
- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- интерактивные анимации, плавная прокрутка и визуальные эффекты;
- SEO-метаданные, карта сайта, robots.txt и Open Graph-разметка.

## Технологии

- Next.js 16 и React 19;
- TypeScript;
- Tailwind CSS;
- Framer Motion;
- Lenis;
- MDX для хранения описаний проектов.

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000).

## Проверка и сборка

```bash
npm run lint
npm run build
```

Проект настроен на статический экспорт. Готовая версия сайта создаётся в каталоге `out` и может быть размещена на любом хостинге статических файлов.

## Основные разделы

- `/` — главная страница и избранные работы;
- `/works/` — полный каталог проектов;
- `/about/` — информация об опыте и компетенциях;
- `/contact/` — контакты и ссылки на профессиональные профили.
