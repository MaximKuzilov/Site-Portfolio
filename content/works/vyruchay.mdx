# Vyruchay! — Student Service Marketplace

"Vyruchay!" is a web platform built as a university project and currently operating as a fully functional marketplace for students. The service allows students to delegate academic tasks (lab assignments, coursework, essays) to peers for compensation — quickly, conveniently, and within a trusted community.

## Features

The platform is built around a role-based interaction model:

* **Client** — registers and creates a task listing with a description, price, and contact information
* **Contractor** — browses the active task feed, selects a suitable assignment, and contacts the client via built-in chat

## Technical Implementation

* Secure registration and authentication with role separation (responding to tasks and creating orders requires an account)
* Built-in chat system for direct communication between clients and contractors
* Task feed with cards displaying title, description, price, date, and contact details
* Relational database (SQLite + Django ORM) for storing users, tasks, and messages
* Deployed and running stably on PythonAnywhere
